# User Guide — ESG Data Platform

## Factory users
1. Log in and open **My Survey**.
2. Work through each section on the left; your progress is shown at the top.
3. Click **Save Draft** anytime — you can come back later.
4. Click **Submit Survey** when all required questions (marked *) are answered.
5. You can edit and resubmit while the survey cycle is still open.
Use **My Profile** to update your name, email, contact details or password.

## Admins
- **Dashboard** — see how many factories have submitted, browse results by factory, category or question, and export reports (Excel / PDF).
- **Survey Cycles** — create a cycle, set its dates, open/close it, or copy questions from a previous cycle.
- **Manage Questions** — from a cycle, add/edit/reorder categories and questions.
- **Factories** — add factories and their login accounts, import many at once with CSV (`name,region,district,contact_email,contact_person,contact_phone,login_email,login_password`), activate/deactivate factories (deactivating also disables its logins).
- **Users & Roles** — create admin or factory-user accounts, deactivate accounts.
- **Forgot password** — use the link on the login page (requires email/SMTP to be configured).
